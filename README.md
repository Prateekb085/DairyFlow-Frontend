# 🥛 DairyFlow Frontend

Modern React frontend for the DairyFlow Milk Collection System.

## 🚀 Tech Stack

- React
- Vite
- Material UI
- React Router
- Axios
- Framer Motion
- MUI X Charts

## ✨ Features

- Responsive Dashboard
- Farmer Management
- Milk Entry Management
- Payment Management
- Reports & Analytics
- JWT Authentication
- Razorpay Integration
- Dark / Light Mode
- Mobile Responsive UI
